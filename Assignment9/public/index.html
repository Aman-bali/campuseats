CS543 Web Services · Assignment 09: API Authentication & Role-Based Access Control

CS543 · Web Services Team 12

Secured Catalogue REST API Dashboard

This developer console exercises the hardened CampusEats Menu / Catalogue REST Service safeguarded by JSON Web Token (JWT) Authentication and a Two-Guard RBAC Architecture. Passwords are salted and hashed using bcryptjs (cost factor 10), token signatures are cryptographically verified using process.env.JWT_SECRET strictly on algorithm HS256, and role claims enforce least-privilege access.

Authors: Aman Bali (20251651015) & Bhupesh Kumar (20251651032) • Instructor: Dr. Pramit Mazumdar (IIIT Vadodara) • Guard Stack: auth (HTTP 401) → requireRole (HTTP 403)

🔍 JWT Token Inspector

Real-time inspection of active Base64URL-encoded headers, claims, and cryptographic status

JWT Architecture Note: JSON Web Tokens are Base64URL-encoded, not encrypted. Anyone who intercepts the token can read the claims. Security rests entirely on the HMAC-SHA256 signature signed with process.env.JWT_SECRET, which prevents tampering.
